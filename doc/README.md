# Documentation

The root `README.md` is the best starting point for this repository. The files in `doc/`
are design notes from development and are useful as reference material, not as the primary
source of truth for setup.

- `CONNECTOR_SPECIFICATIONS.md` — external data source notes for Berlin Geoportal and OSM
- `FRONTEND_IMPLEMENTATION.md` — HTMX/Jinja frontend approach and UI structure
